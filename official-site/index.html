核心主张

教学决策权归服务的确定性算法，LLM 降级为教具。

现有 AI 学习工具的一切毛病，根源是把「当老师」交给了 LLM——它没有你的长期状态，不知道你的知识边界， 也没有动机拦住你说「这题没懂，不许走」。面霸把凡是能算清楚的决策全部收进服务端：

「能算清楚的，一律不进 Prompt。」
选哪题、分怎么算、闸门怎么拦、间隔多久、要不要去重 —— 都由确定性算法决定，可复现、可审计。
产品特性

像一位真的老师那样，一直盯着你。

一套完整的「学习 → 作答 → 判分 → 复习 → 沉淀」闭环，外加真实面试演练。

分层知识图谱

概念按 layer 1–5 由浅入深组织，选题闸门优先从底层未掌握的点起步，保证永远学到新东西。

先教后考

进入练习前把知识点拆成 3–8 个子点，逐个讲解再做；讲解流式生成，支持 Markdown、代码高亮与 Mermaid。

理解型判分

判分前先确定老师实际问过什么，只评被问到的内容；看意思不看措辞，换种说法、意思一致即算命中。

FSRS 间隔排程

AGAIN/HARD/GOOD/EASY 四档，到期自动复习；没过当天重来。掌握度按概念粒度持续更新。

7 种认知探针题型

RECALL / CLOZE / REVERSE / TRAP / SCENARIO / CONTRAST / INTEGRATION，换形式反复检测，杜绝只背答案。

对话沉淀 + 知识卡片

自由问答一键收敛成知识卡片，当天到期进内化复盘；复习反馈同步回写掌握画像，沉淀不脱钩。

两种备考场景

学习与面试，一套系统全搞定。

不是刷题库，而是一个知道你学到第几层、该复习什么、没搞懂就不许往前走的学习型 Agent。

LEARN · 学习模式

日常学习 / 备考。先教后考：知识拆解 → 逐子点讲解 → 对话式作答 → 理解型判分，一题一闭环。

REHEARSAL · 模拟面试

面试前冲刺。闭卷、强制倒计时、提交后不可编辑、追问封顶 2 轮，用文字模拟「说出口收不回」的压力。

INTERVIEW · 完整面试

选面试方式、依据（简历 + 学习方向）、难度与题数，逐题流式问答并逐题回顾，结束后 AI 评估打分。

下载安装

桌面应用，双模式开箱即用。

安装包自带精简 JRE + 后端，无需配置 Java、Docker 或数据库；也可连接你自己的服务器。

Windows

推荐使用 .exe 安装版以获得完整的自动更新能力；.zip 用于便携运行。

macOS

提供苹果芯片（arm64）与 Intel（x64）两种架构；未签名时首次启动请右键「打开」。

版本与下载链接由 GitHub Releases 实时读取 —— 发布新 release 后此页面会自动更新，无需手动改代码。
更多历史版本见 GitHub Releases； 源码与说明见 GitHub 仓库。
